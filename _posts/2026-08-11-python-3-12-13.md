## Python 3.12.13

**Release date:** March 3, 2026

## Security content in this release

* [gh-144125](https://github.com/python/cpython/issues/144125): [`BytesGenerator`](https://docs.python.org/release/3.12.13/library/email.generator.html#email.generator.BytesGenerator) will now refuse to serialize (write) headers that are unsafely folded or delimited; see [`verify_generated_headers`](https://docs.python.org/release/3.12.13/library/email.policy.html#email.policy.Policy.verify_generated_headers). (Contributed by Bas Bloemsaat and Petr Viktorin in [gh-121650](https://github.com/python/cpython/issues/121650)).
* [gh-143935](https://github.com/python/cpython/issues/143935): Fixed a bug in the folding of comments when flattening an email message using a modern email policy. Comments consisting of a very long sequence of non-foldable characters could trigger a forced line wrap that omitted the required leading space on the continuation line, causing the remainder of the comment to be interpreted as a new header field. This enabled header injection with carefully crafted inputs.
* [gh-143925](https://github.com/python/cpython/issues/143925): Reject control characters in data: URL media types.
* [gh-143919](https://github.com/python/cpython/issues/143919): Reject control characters in [`http.cookies.Morsel`](https://docs.python.org/release/3.12.13/library/http.cookies.html#http.cookies.Morsel) fields and values.
* [gh-143916](https://github.com/python/cpython/issues/143916): Reject C0 control characters within wsgiref.headers.Headers fields, values, and parameters.
* [gh-142145](https://github.com/python/cpython/issues/142145): Remove quadratic behavior in `xml.minidom` node ID cache clearing. In order to do this without breaking existing users, we also add the _ownerDocument_ attribute to [`xml.dom.minidom`](https://docs.python.org/release/3.12.13/library/xml.dom.minidom.html#module-xml.dom.minidom) elements and attributes created by directly instantiating the `Element` or `Attr` class. Note that this way of creating nodes is not supported; creator functions like [`xml.dom.Document.documentElement()`](https://docs.python.org/release/3.12.13/library/xml.dom.html#xml.dom.Document.documentElement) should be used instead.
* [gh-137836](https://github.com/python/cpython/issues/137836): Add support of the “plaintext” element, RAWTEXT elements “xmp”, “iframe”, “noembed” and “noframes”, and optionally RAWTEXT element “noscript” in [`html.parser.HTMLParser`](https://docs.python.org/release/3.12.13/library/html.parser.html#html.parser.HTMLParser).
* [gh-136063](https://github.com/python/cpython/issues/136063): [`email.message`](https://docs.python.org/release/3.12.13/library/email.message.html#module-email.message): ensure linear complexity for legacy HTTP parameters parsing. Patch by Bénédikt Tran.
* [gh-136065](https://github.com/python/cpython/issues/136065): Fix quadratic complexity in [`os.path.expandvars()`](https://docs.python.org/release/3.12.13/library/os.path.html#os.path.expandvars).
* [gh-119451](https://github.com/python/cpython/issues/119451): Fix a potential memory denial of service in the [`http.client`](https://docs.python.org/release/3.12.13/library/http.client.html#module-http.client) module. When connecting to a malicious server, it could cause an arbitrary amount of memory to be allocated. This could have led to symptoms including a [`MemoryError`](https://docs.python.org/release/3.12.13/library/exceptions.html#MemoryError), swapping, out of memory (OOM) killed processes or containers, or even system crashes.
* [gh-119452](https://github.com/python/cpython/issues/119452): Fix a potential memory denial of service in the [`http.server`](https://docs.python.org/release/3.12.13/library/http.server.html#module-http.server) module. When a malicious user is connected to the CGI server on Windows, it could cause an arbitrary amount of memory to be allocated. This could have led to symptoms including a [`MemoryError`](https://docs.python.org/release/3.12.13/library/exceptions.html#MemoryError), swapping, out of memory (OOM) killed processes or containers, or even system crashes.
* [gh-119342](https://github.com/python/cpython/issues/119342): Fix a potential memory denial of service in the [`plistlib`](https://docs.python.org/release/3.12.13/library/plistlib.html#module-plistlib) module. When reading a Plist file received from untrusted source, it could cause an arbitrary amount of memory to be allocated. This could have led to symptoms including a [`MemoryError`](https://docs.python.org/release/3.12.13/library/exceptions.html#MemoryError), swapping, out of memory (OOM) killed processes or containers, or even system crashes.
